Тумблер для Linux
=================

Пускает через твой VPN только выбранные приложения, а остальные (игры, браузер и т.д.) оставляет напрямую.
Нужен VPN-клиент с локальным портом SOCKS5: Karing, v2rayN, NekoBox/Throne, Hiddify, Clash Verge и другие.

Как запустить
1. Распакуй архив.
2. Открой терминал в папке tumbler и выполни:  ./tumbler
   (двойной щелчок тоже может сработать, если файловый менеджер разрешает запуск программ)
3. Окно предложит установить службу — понадобится пароль администратора.
   После установки «Тумблер» появится в меню приложений, а эту папку можно удалить.

Требования
- 64-битный Linux на Intel/AMD (x86_64), ядро 5.13 или новее
- systemd, nftables, iproute2
- подходят Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora 36+, Arch, openSUSE Tumbleweed

Управление из терминала
  tumbler status    — что работает
  tumbler pause     — всё напрямую
  tumbler resume    — снова через VPN
  tumbler toggle    — переключить (удобно повесить на горячую клавишу в настройках рабочего стола)

Удаление: Настройки → «Удалить службу…» или  sudo /opt/tumbler/tumbler uninstall
Журнал службы: journalctl -u tumbler

Эта версия собрана без проверки на настоящем Linux. Если что-то не работает — пришли вывод
  tumbler status
  journalctl -u tumbler -n 100
и отчёт из окна «Диагностика».

Внутри — hev-socks5-tunnel 2.18.0 (лицензия MIT, https://github.com/heiher/hev-socks5-tunnel).
